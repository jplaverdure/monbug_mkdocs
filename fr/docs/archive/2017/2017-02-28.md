# Février - BioHackathon (Association étudiante de bio-informatique de l'UdeM)

!!! info "Détails de l'évènement"

    **Date/Heure:**

    Mardi, 28 février 2017

L'association étudiante de bio-informatique de l'Université de Montréal a organisé un hackathon le 28 février ([biohackudem.com](http://biohackudem.com/)).

Bonne chance à tous les participants, et félicitations aux organisateurs d'avoir mis en place ce bel événement.
