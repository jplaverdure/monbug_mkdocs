# MonBUG Website

This repository contains the source code which builds the MonBUG website.  
The contents of the site are written in Markdown and are processed into a static site using python and mkdocs.

## Getting Started

As a developer working on the website you will need to have python3 installed. 
Use of a virtual environment is highly recommended.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The site is bilingual and essentially holds 2 separate mkdocs projects, 1 per language.
It roughly follows the ([folder structure detailed here](https://github.com/squidfunk/mkdocs-material/discussions/2346)
To render the docs and re-render on changes you can start the development server as follows:

```bash
# start the french version 
mkdocs serve -f fr/mkdocs.yml

# start the english version
mkdocs serve -f en/mkdocs.yml
```

Your build docs should now be available on localhost:8000

## Build

The site can be built by running the build command twice, once for each language
```bash
cd fr
mkdocs build
cd ../en
mkdocs build
```

# Additional step

A basic index.html file containing a redirect to the french version of the site can be generated by running:  
(This step is only required once and does not need to be re-executed for each new build of the sites)
```bash
cd <base_folder_of_project>
mkdocs build
```

# Deployment 

```bash
# this command requires an ssh key be deployed on the receiving server
cd docs
rsync -avz ./* <host>:<host_folder>
```

## Useful Tools

When editing the markdown docs I reccommend using vscode and installing a few helpful markdown extensions. These extensions will do helpful things like auto-formatting lists, auto-adding table of contents etc. The liting will also help you see when you have made any style errors in your markdown file

- markdownlint ([DavidAnson.vscode-markdownlint](https://marketplace.visualstudio.com/items?itemName=DavidAnson.vscode-markdownlint))
- Markdown All in One ([yzhang.markdown-all-in-one](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one))

After you have added the extensions, put the following line in your settings.json (or using the GUI version) for vscode

```json
    "yaml.schemas": {
        "https://squidfunk.github.io/mkdocs-material/schema.json": "mkdocs.yml"
    },
    "yaml.customTags": [
        "!ENV scalar",
        "!ENV sequence",
        "!relative scalar",
        "tag:yaml.org,2002:python/name:material.extensions.emoji.to_svg",
        "tag:yaml.org,2002:python/name:material.extensions.emoji.twemoji",
        "tag:yaml.org,2002:python/name:pymdownx.superfences.fence_code_format",
        "tag:yaml.org,2002:python/object/apply:pymdownx.slugs.slugify mapping"
    ]
```
